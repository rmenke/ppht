Detailed Description

template<std::size_t Major>
class ppht::channel::axial_scanner< Major >

A scanner optimized for axial lines.

The axial scanner is optimized for handling lines perpendicular to an axis; that is, horizontal and vertical lines.

The Major template parameter controls the orientation of the line. If it is zero, the line is horizontal; if it is one, the line is vertical.

Template Parameters
Majorthe axis along which the point will be moved
