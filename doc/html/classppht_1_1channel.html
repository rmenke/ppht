Detailed Description

An object representing a line segment between two points.

A channel instance is an immutable factory object that acts as a pseudo-container for range-based iteration. The values produced are sets of points describing a perpendicular line segment intersecting a canonical point on the ideal line between the two endpoints. In rare cases the canonical point may not be a member of the point set, but is adjacent to one.

Typical use case:

for (const auto &[canon, pts] : channel{p1, p2, rdus}) {
for (const auto &[x, y] : pts) {
if (test(x, y)) {
segment.insert(canon);
break;
}
}
}

Construct a channel with given radius between two points.

The radius parameter controls how wide the channel is. It is the half-width of the channel including the reference pixel. For example, a radius of 3 would create a channel 5 pixels wide.

Construct the appropriate scanner based on the delta vector.

This is a virtual constructor that selects which instance to create by examining the delta vector. It determines which axis has the greater rate of change — the major axis — and if there is any change along the minor axis. If the rate of change along the minor axis is zero, then the function returns a scanner that is optimized for that.
